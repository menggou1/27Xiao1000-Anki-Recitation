> **注意：** 本项目仅包含“傻背题”（需要记忆固定答案的题目），不是完整的肖1000题库。

## 下载与导入

### 方法一：从 Release 下载（推荐）

1. 打开项目的 [Releases 页面](https://github.com/menggou1/27Xiao1000-Anki-Recitation/releases)。
2. 进入 `1.0` 版本。
3. 在 **Assets** 中下载 `27.1000.apkg`。
4. 使用 Anki 桌面端打开该文件，或在 Anki 中选择：
   
   `文件 → 导入`

5. 导入完成后，即可在 `27肖1000傻背题` 顶层卡组下按科目复习。

### 方法二：下载仓库中的卡组文件

仓库根目录也提供了 Anki 卡组文件：[`27肖1000傻背题.apkg`](./27%E8%82%961000%E5%82%BB%E8%83%8C%E9%A2%98.apkg)。

如果通过 GitHub 网页下载不方便，建议优先使用 Release 中的 `27.1000.apkg` 文件。

## 仓库文件

```text
.
├── 27肖1000傻背题.apkg   # Anki 卡组文件，可直接导入
├── origin.txt             # 原始题目与答案文本，便于查阅和校对
└── README.md              # 项目说明
```

`origin.txt` 保存了原始闪卡内容，题目以“正面”呈现，答案以“背面”呈现，例如：

- 正面：马克思主义的基本特征，如果用一句话来概括就是____
- 背面：科学性与革命性的统一

## 本版本整理内容

- 将原始资料转换为 Anki `.apkg` 格式。
- 按马原、毛中特、新思想、史纲、思修建立独立子卡组。
- 将原始资料中交替排列的题目正确归类。
- 去除卡片序号及与背诵无关的公众号声明。
- 保留题目与答案，方便导入 Anki 后直接复习。

## 使用建议

- 首次导入后，可以先检查卡组设置，再根据自己的复习计划调整每日新卡和复习上限。
- 建议结合 Anki 的间隔重复机制进行长期复习，不要只在考前集中刷卡。
- 对于答案较长的卡片，可以在复习时拆分理解，必要时自行添加备注或修改卡片内容。
- 如发现题目、答案或分类存在问题，欢迎通过 [Issues](https://github.com/menggou1/27Xiao1000-Anki-Recitation/issues) 反馈。
